WEBSITE TUYỂN DỤNG VIỆT HƯƠNG GROUP

1. Mở file index.html bằng Chrome/Safari để xem.
2. Website tương thích máy tính và điện thoại.
3. Form ứng tuyển hiện dùng mailto (mở ứng dụng email). Muốn nhận CV trực tiếp cần kết nối backend, Google Form, Formspree hoặc hệ thống ATS.
4. Có thể chỉnh nội dung vị trí trong file index.html và script.js.
